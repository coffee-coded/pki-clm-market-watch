## Significant

### CyberArk (Venafi's parent) is now "Idira" — missed since May
Palo Alto Networks, having completed its ~$25B acquisition of CyberArk
(Feb 11, 2026), folded the entire CyberArk portfolio into a new brand,
**Idira**, in a phased rollout starting May 31, 2026. **"CyberArk
Certificate Manager" (formerly Venafi TLS Protect) is now sold as "Idira
Certificate Manager."** This tracker's baseline digest and every daily run
since Sept 15 missed the rebrand — routine PR/product searches kept
surfacing the old "CyberArk Certificate Manager" name. Caught 2026-09-25.
**Action:** `watchlist.md`'s "Venafi (now part of CyberArk)" line should be
updated to reference Idira; this tracker will now search "Idira" alongside
"Venafi"/"CyberArk" each run.
[Findings detail](../findings/2026-09-25.md)

### DigiCert breached in April; 60 fraudulent EV code-signing certs used to sign malware
An attacker social-engineered DigiCert's support chat with a malicious
screensaver file, exploiting a support endpoint with faulty endpoint
protection, on April 2, 2026. This yielded 60 fraudulently-issued EV
Code Signing certificates, at least 11 of which were used to sign "Zhong
Stealer" malware payloads (briefly causing Microsoft Defender false-positive
chaos on legitimately-signed software elsewhere). DigiCert revoked all 60
certs by April 17 and removed support staff's ability to view certificate
initialization codes. A clear-cut, on-topic CA breach that both the
baseline digest and daily runs missed until caught 2026-09-27.
**Action:** this tracker will periodically run explicit "[vendor]
breach/CVE/incident" sweeps across the full watchlist, not just PR-style
queries on the primary three vendors, to catch standalone security
reporting like this.
[Findings detail](../findings/2026-09-27.md)
