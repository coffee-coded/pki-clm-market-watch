### [SIGNIFICANT] DigiCert breached via social-engineered support attack; 60 fraudulent EV code-signing certificates issued, used to sign malware
- **Date:** Attack occurred April 2, 2026; certificates revoked by April 17, 2026; surfaced in this tracker today, 2026-09-27
- **Source:** Help Net Security, https://www.helpnetsecurity.com/2026/05/04/digicert-breach-code-signing-certificates-malware/ ; GBHackers, https://gbhackers.com/digicert-hacked-in-screensaver-based-attack/ ; Blackswan Cybersecurity threat advisory, https://blackswan-cybersecurity.com/threat-advisory-digicert-compromise-april-2026-may-7-2026/
- **Summary:** An attacker social-engineered DigiCert's customer support chat, delivering a malicious .scr (Windows screensaver) file disguised as a customer screenshot to a support endpoint that had faulty EDR coverage. This let the attacker fraudulently obtain 60 Extended Validation (EV) Code Signing certificates — the highest-trust code-signing tier — and use at least 11 of them to sign payloads for the "Zhong Stealer" malware family, which briefly caused Microsoft Defender false-positive chaos as it flagged legitimately-signed software. DigiCert revoked all 60 certificates by April 17 and removed support staff's ability to view certificate initialization codes as a remediation. **Directly on-topic for this watchlist** (a disclosed CA breach affecting a major secondary vendor, involving code-signing management — an explicit watchlist topic) but missed by both the 2026-09-15 baseline digest and every daily run since. Worth treating as a standing caution: this tracker's web searches keep surfacing recent PR/product news readily but can miss standalone security-incident reporting unless specifically queried (as with the Idira rebrand on 2026-09-25). Recommend an occasional explicit "[vendor] breach/incident/CVE" sweep across the full watchlist, not just the primary three, to catch these.
